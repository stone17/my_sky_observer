## General
- When asking for GUI, use Python FAST API for the backend and HTML and Javescript for the frontend

## Frontend UI
- Create a settings page to allow chaning settings (should be linked to a user_config.yaml)
- Use a lean interface, avoid having overly large buttons and panels
- Panels should have hover and shadow effect
- use a left side expandable panel for switching between settings and main (or other required pages)
- make sure the ui works on small screens (phones)
- for small screens turn the side panel to a top panel
- inform the user about errors in toast messages (they should not disappear by themselves but have a close x)

## Coding Style Python
- Use object oriented best coding practices
- Use classes (parent and child inheritences)
- Reduce scope of varaibles as much as possible
- Avoid writing multiple functions doing the same or similar things
- Structure code in files based on their function. Do not create one long file.
- Structue code in folders for backend and frontend
- Create dicts to consolidate information similar to the use of structs in C.
- always catch errors and print the actual error, dont silently drop them

## Coding Style HTML/Javescript
- Avoid writing multiple functions doing the same or similar things
- Structure code in files based on their function. Do not create one long file.
- Separate Javescript and HTML into different files
- Reduce scope of varaibles as much as possible
